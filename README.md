# Scaleon

Marketing site for Scaleon, the Gulf’s outbound growth system. It follows the New Website desktop composition in the SCALE-ON Figma file: hero, signal-to-deal, operating stages, lead workspace, compounding chart, customer stories, and the mountain signup.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3457](http://localhost:3457).

## Use the page

- **Start a Campaign** opens a request form. A valid work email confirms the request.
- **Growth** in the header jumps to the signal, operating, pipeline, and customer sections.
- The four stage tabs (Position, Build, Launch, Compound) switch the operating view.
- The lead workspace search filters the imported list.
- Review bars switch the story order.
- The footer email field confirms an address or asks for a valid one.
